# PRDYELE0029 LIOT 0.0.6

Allineamento alle funzioni LIOT consolidate su SCTECH0077:

- OTA Wi-Fi e recupero sicuro da un OTA BLE interrotto;
- reset completo alla dissociazione, scene, playlist e gruppi affidabili;
- sincronizzazione e salvataggio degli scenari personalizzati sui controller.

La gestione LED PRDYELE0029 resta invariata: nessuna modifica a mappatura,
ordine RGBW o limite hardware dei canali.
