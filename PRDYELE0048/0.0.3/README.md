# PRDYELE0048 · LIOT · firmware 0.0.3

Aggiornamento OTA per il controllo di gruppo con touchscreen PRDYTOUCH.

- ricezione ESP-NOW dei comandi master autenticati dal radioID del gruppo;
- accensione, spegnimento, statico, arcobaleno e colori fissi RGB;
- il pacchetto viene ignorato se appartiene a un altro gruppo.
